# Twelve by Twelve

A multiplication and division facts trainer for kids. Plain HTML, CSS, and JavaScript with no build step.

## Play

Open `index.html` in a browser, or visit the GitHub Pages site once deployed.

- Tap the correct answer out of three choices.
- Swipe left (or press `S`) to open the settings drawer.
- Choose a mode: **Practice**, **Survival**, or **Timed Challenge** (race to 50 points).
- Toggle multiplication and division, and pick which facts (1 through 12) to practice.

Settings and personal bests are saved in the browser.

## Deploy

Pushing to `main` runs `.github/workflows/deploy.yml`, which publishes the repository root to GitHub Pages.

One-time setup in the repository on GitHub: **Settings → Pages → Build and deployment → Source: GitHub Actions**.
